1. ReAct 概述

1.1 什么是 ReAct

ReAct(Reasoning + Acting)是一种将推理(Reasoning)与行动(Acting)交织进行的 Agent 架构模式。由普林斯顿大学和 Google Research 的 Yao 等人于 2022 年提出。

核心思想: 让 LLM 以交错的方式生成推理轨迹(Reasoning Traces)和任务相关行动(Task-specific Actions),使两者协同工作: 推理指导行动,行动反馈又促进更好的推理。

1.2 为什么需要 ReAct

传统方法的问题:

ReAct 的解决方案:

思考 -> 行动 -> 观察 -> 思考 -> 行动 -> 观察 -> ... -> 答案
  ^___________________________________________|
              实时反馈循环

1.3 ReAct 的优势

  1. 幻觉抑制: 通过外部工具验证事实,减少模型编造

  2. 可解释性: 推理轨迹透明,可追踪决策过程

  3. 交互性: 能与外部环境动态交互,适应变化

  4. 鲁棒性: 单步错误可通过后续观察发现并修正

  5. 通用性: 适用于问答、决策、网页导航、工具使用等多种任务

2. 理论基础

2.1 论文来源

ReAct: Synergizing Reasoning and Acting in Language Models Shunyu Yao, Jeffrey Zhao, Yuhan Du, Izhak Shafran, Karthik Narasimhan, Yuan Cao Princeton University & Google Research, 2022

2.2 核心假设

ReAct 基于以下关键洞察:

人类解决复杂任务时,推理和行动是紧密交织的。 我们不仅"思考",还会"行动"来获取信息、验证假设,然后根据反馈调整思考。

认知科学基础:

  • 双重过程理论: 系统1(直觉/行动)与系统2(推理/分析)的协同

  • Situated Cognition: 认知嵌入在具体情境和行动中

  • 感知-行动循环: 生物体通过行动改变环境,通过感知获取反馈

2.3 形式化定义

设任务为 T,环境为 E,LLM 为 M,ReAct 可形式化为:

​x
对于每一步 t:
    Thought_t = M(Prompt + 历史轨迹 + 任务T)
    Action_t = 从 Thought_t 提取行动指令
    Observation_t = E.execute(Action_t)
    将 (Thought_t, Action_t, Observation_t) 加入历史轨迹


直到 Action_t 为终止行动(Finish)或达到最大步数

3.2 核心组件详解

3.2.1 推理模块(Thought Generator)

职责:

  • 分析当前状态和目标差距

  • 制定下一步策略

  • 分解复杂问题

  • 评估已有信息是否足够

输出格式:

xxxxxxxxxx
Thought: [自然语言推理过程]

关键能力:

  • 元认知: "我是否需要更多信息?"

  • 假设检验: "基于当前观察,假设X是否成立?"

  • 计划调整: "原计划A行不通,改为计划B"

3.2.2 行动模块(Action Executor)

职责:

  • 将推理转化为具体行动

  • 调用外部工具/API

  • 执行环境操作

  • 处理行动结果

输出格式:

xxxxxxxxxx
Action: [工具名][参数]

行动类型:

3.2.3 观察模块(Observation Parser)

职责:

  • 解析工具返回的原始数据

  • 提取关键信息

  • 格式化以便 LLM 理解

  • 检测错误和异常

输出格式:

xxxxxxxxxx
Observation: [格式化后的结果]

5.4 高级 Prompt 技巧

5.4.1 强制推理格式

xxxxxxxxxx
每次 Thought 必须包含以下要素之一:
1. [分析] 对当前情况的分析
2. [计划] 下一步行动计划
3. [验证] 对已有信息的验证
4. [修正] 对错误方向的修正

5.4.2 行动约束

xxxxxxxxxx
Action 必须遵循以下规则:
- 每次只能调用一个工具
- 参数必须包含在方括号内
- 如果信息不足,优先使用 Search 而非猜测
- 如果连续3次搜索无结果,尝试改变关键词

5.4.3 自我修正提示

xxxxxxxxxx
如果 Observation 显示错误或异常,你必须:
1. 在 Thought 中分析错误原因
2. 提出修正方案
3. 执行修正后的 Action

6. 代码实现

6.1 基础实现(Python)

xxxxxxxxxx
import re
from typing import List, Dict, Any, Tuple
from dataclasses import dataclass


@dataclass
class Step:
    thought: str
    action: str
    observation: str


class ReActAgent:
    def __init__(self, llm, tools: Dict[str, callable], max_steps: int = 10):
        self.llm = llm
        self.tools = tools
        self.max_steps = max_steps
        self.trajectory: List[Step] = []


    def run(self, question: str) -> str:
        prompt = self._build_prompt(question)
        for step in range(self.max_steps):
            response = self.llm.generate(prompt)
            thought, action = self._parse_response(response)
            if action.startswith("Finish["):
                return self._extract_finish(action)
            tool_name, params = self._parse_action(action)
            if tool_name not in self.tools:
                observation = f"Error: Tool not found."
            else:
                try:
                    observation = str(self.tools[tool_name](params))
                except Exception as e:
                    observation = f"Error: {str(e)}"
            self.trajectory.append(Step(thought, action, observation))
            prompt += f"\nThought: {thought}\nAction: {action}\nObservation: {observation}\nThought:"
        return self._force_finish(prompt)


    def _build_prompt(self, question: str) -> str:
        tool_desc = "\n".join([f"{name}: {func.__doc__}" for name, func in self.tools.items()])
        return f"""你正在解决一个问题。你可以使用以下工具:


{tool_desc}


请按以下格式思考:
Thought: [你的推理过程]
Action: [工具名称][参数]


当你认为有足够信息时:
Thought: [总结]
Action: Finish[最终答案]


Question: {question}
Thought:"""


    def _parse_response(self, response: str) -> Tuple[str, str]:
        thought_match = re.search(r'Thought:\s*(.+?)(?=\nAction:|$)', response, re.DOTALL)
        action_match = re.search(r'Action:\s*(.+?)(?=\n|$)', response, re.DOTALL)
        thought = thought_match.group(1).strip() if thought_match else ""
        action = action_match.group(1).strip() if action_match else ""
        return thought, action


    def _parse_action(self, action: str) -> Tuple[str, str]:
        match = re.match(r'(\w+)\[(.*)\]', action)
        if match:
            return match.group(1), match.group(2)
        return "", ""


    def _extract_finish(self, action: str) -> str:
        match = re.match(r'Finish\[(.*)\]', action)
        return match.group(1) if match else ""


    def _force_finish(self, prompt: str) -> str:
        prompt += "\n已达到最大步数。请基于已有信息给出最佳答案。\nThought: 基于已有信息,\nAction: Finish["
        response = self.llm.generate(prompt)
        return self._extract_finish(response)

6.3 使用 LangGraph 实现(2026推荐)

xxxxxxxxxx
from langgraph.graph import StateGraph, END
from langchain_core.messages import HumanMessage, AIMessage
from typing import TypedDict, Annotated
import operator


class ReActState(TypedDict):
    messages: Annotated[list, operator.add]
    next_step: str


class ReActGraph:
    def __init__(self, llm, tools):
        self.llm = llm
        self.tools = {t.name: t for t in tools}
        self.graph = self._build_graph()


    def _build_graph(self):
        workflow = StateGraph(ReActState)
        workflow.add_node("reason", self._reason)
        workflow.add_node("act", self._act)
        workflow.add_node("observe", self._observe)
        workflow.set_entry_point("reason")
        workflow.add_edge("reason", "act")
        workflow.add_edge("act", "observe")
        workflow.add_conditional_edges(
            "observe",
            self._should_continue,
            {"continue": "reason", "end": END}
        )
        return workflow.compile()


    def _reason(self, state: ReActState):
        messages = state["messages"]
        response = self.llm.invoke(messages + [HumanMessage(content="What should I do next?")])
        return {"messages": [response]}


    def _act(self, state: ReActState):
        last_message = state["messages"][-1].content
        tool_name, params = self._parse_action(last_message)
        if tool_name in self.tools:
            result = self.tools[tool_name].invoke(params)
            return {"messages": [AIMessage(content=f"Observation: {result}")]}
        return {"messages": [AIMessage(content="Observation: Tool not found")]}


    def _observe(self, state: ReActState):
        return state


    def _should_continue(self, state: ReActState):
        last_message = state["messages"][-1].content
        if "Finish[" in last_message or "Final Answer:" in last_message:
            return "end"
        return "continue"


    def run(self, question: str):
        return self.graph.invoke({
            "messages": [HumanMessage(content=question)],
            "next_step": "reason"
        })

class ReflexionReAct(ReActAgent):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.reflections: List[str] = []


    def run_with_reflexion(self, question: str, max_attempts: int = 3):
        for attempt in range(max_attempts):
            try:
                answer = self.run(question)
                is_correct = self._evaluate(answer, question)
                if is_correct:
                    return answer
                reflection = self._generate_reflection()
                self.reflections.append(reflection)
                self.trajectory = []
            except Exception as e:
                reflection = f"Error occurred: {str(e)}. Need to be more careful."
                self.reflections.append(reflection)
        return self._best_effort_answer()


    def _generate_reflection(self) -> str:
        prompt = "基于以下失败的尝试,分析错误原因并提出改进建议:


轨迹:
{self._format_trajectory()}


反思:"""
        return self.llm.generate(prompt)


    def _build_prompt(self, question: str) -> str:
        base = super()._build_prompt(question)
        if self.reflections:
            reflections = "\n".join([f"- {r}" for r in self.reflections])
            base += f"\n\n之前的经验教训:\n{reflections}\n"
        return base

class CachedToolExecutor:
    def __init__(self, tools, cache_ttl: int = 3600):
        self.tools = tools
        self.cache = {}
        self.cache_ttl = cache_ttl


    def execute(self, tool_name: str, params: str):
        cache_key = (tool_name, hash(params))
        if cache_key in self.cache:
            result, timestamp = self.cache[cache_key]
            if time.time() - timestamp < self.cache_ttl:
                return result
        result = self.tools[tool_name](params)
        self.cache[cache_key] = (result, time.time())
        return result

class ParallelReAct(ReActAgent):
    def _execute_actions(self, actions: List[Tuple[str, str]]) -> List[str]:
        with ThreadPoolExecutor() as executor:
            futures = [
                executor.submit(self.tools[name], params)
                for name, params in actions
            ]
            return [f.result() for f in futures]


    def _parse_parallel_actions(self, response: str) -> List[Tuple[str, str]]:
        actions = []
        for match in re.finditer(r'Action\d*: \s*(\w+)\[(.*?)\]', response):
            actions.append((match.group(1), match.group(2)))
        return actions

    def _detect_redundancy(self, trajectory: List[Step]) -> List[int]:
        redundant_steps = []

        for i, step in enumerate(trajectory):
            action_key = step.action
            if action_key in seen_actions:

            seen_actions.add(action_key)
        return redundant_steps
