# CUDA 编程技能

## 核心能力

- **内核开发**：编写高效的 CUDA 内核，处理大规模并行计算任务
- **内存优化**：掌握共享内存、常量内存和纹理内存的使用策略
- **流与事件**：利用 CUDA 流实现异步执行和流水线并行

## 常用技术

| 技术 | 应用场景 |
|------|---------|
| 共享内存 Bank Conflict 避免 | 矩阵转置、卷积计算 |
| Warp Shuffle 指令 | 归约、扫描操作 |
| Cooperative Groups | 跨块同步、网格级协作 |
| CUDA Graphs | 推理优化、重复执行模式 |
