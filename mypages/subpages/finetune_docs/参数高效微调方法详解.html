参数高效微调方法详解

一、概述

参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）是一类在保持预训练模型大部分参数冻结的前提下，仅通过引入少量额外参数或选择性地更新少量参数来适配下游任务的方法。与全参数微调相比，PEFT 显著降低了计算资源需求和存储开销，同时有效缓解了灾难性遗忘问题。

二、LoRA（Low-Rank Adaptation）

2.1 核心思想

LoRA 基于一个关键假设：模型权重在微调过程中的变化具有低秩结构。即权重更新矩阵 ΔW 可以表示为两个低秩矩阵的乘积：

xxxxxxxxxx
W' = W + ΔW = W + BA

其中：

  • W ∈ R^{d×k}：预训练权重矩阵（冻结）

  • B ∈ R^{d×r}：低秩矩阵（可训练）

  • A ∈ R^{r×k}：低秩矩阵（可训练）

  • r << min(d, k)：秩远小于原始维度

2.2 训练机制

xxxxxxxxxx
输入 x
    ├──→ W × x（冻结，预训练权重）
    └──→ B × A × x（可训练，低秩增量）
              ↓
         输出 = W×x + α/r × B×A×x

  • A 初始化：随机高斯初始化

  • B 初始化：零初始化（确保训练开始时 ΔW = 0，即从预训练状态开始）

  • 缩放因子：α/r（通常 α = 2r）

2.3 为什么有效

  • 过度参数化假设：预训练模型具有过度参数化的特性，权重矩阵的"有效秩"远低于其名义维度

  • 任务特定子空间：微调只需在权重空间的一个低维子空间内调整即可适配新任务

  • 梯度高效：反向传播只需通过 B 和 A，计算量远小于更新完整 W

2.6 LoRA 变体

2.6.1 QLoRA

将 LoRA 与 4-bit 量化结合：

  • 基座模型以 4-bit NF4 格式存储

  • 计算时动态解量化到 BF16

  • 分页优化器防止 OOM

  • 7B 模型仅需 ~8GB 显存

详见《QLoRA 量化微调详解》文档。

2.6.2 DoRA（Weight-Decomposed LoRA）

将权重分解为幅度和方向两个分量：

xxxxxxxxxx
W' = m × (W/||W|| + ΔW_direction)

  • m：可训练幅度标量

  • ΔW_direction：LoRA 低秩方向更新

  • 更精细地控制权重更新，效果优于标准 LoRA

2.6.3 AdaLoRA（Adaptive LoRA）

动态调整各层的秩：

  • 基于奇异值分解（SVD）初始化

  • 训练过程中根据重要性评分剪枝不重要的奇异值

  • 自动为不同层分配不同的有效秩

  • 在相同参数预算下效果优于固定秩 LoRA

2.6.4 rsLoRA（Rank-Stabilized LoRA）

解决大秩 LoRA 的训练稳定性问题：

  • 缩放因子从 α/r 改为 α/√r

  • 允许使用更大的秩（如 r=512, 1024）而不损失稳定性

  • 适合需要强表达能力的复杂任务

三、Adapter（适配器）

3.1 核心思想

Adapter 在 Transformer 的每个子层中插入小型神经网络模块（瓶颈结构），仅训练这些插入模块，冻结原始预训练参数。

3.2 架构设计

​x
原始 Transformer 层：
  x → [Self-Attention] → x' → [Feed-Forward] → output


插入 Adapter 后：
  x → [Self-Attention] → x' → [Adapter] → x'' → [Feed-Forward] → x''' → [Adapter] → output


Adapter 内部结构：
  input → Linear(d→m) → ReLU/GELU → Linear(m→d) → output
          └────────────┘
           bottleneck
           (m << d)

  • 下投影：d → m（将高维特征压缩到低维瓶颈）

  • 非线性激活：ReLU 或 GELU

  • 上投影：m → d（恢复原始维度）

  • 残差连接：Adapter 输出与输入相加

3.3 两种插入位置

通常在每个 Transformer 层的两个子层后都插入 Adapter。

3.4 参数效率

  • 瓶颈维度 m 通常设为原始维度 d 的 1/64 ~ 1/4

  • 例如 d=4096, m=64 时，每个 Adapter 仅需约 0.5M 参数

  • 一个 24 层的模型，总 Adapter 参数约 12M（占原模型 0.3%）

3.5 特点与局限

优势：

  • 模块独立：每个任务的 Adapter 完全独立，便于多任务切换

  • 推理灵活：可动态加载/卸载不同任务的 Adapter

  • 训练稳定：Adapter 的残差结构保证训练初期输出接近恒等映射

局限：

  • 推理延迟：前向传播需额外经过 Adapter 模块，增加推理时间

  • 层间耦合：Adapter 插入位置固定，无法灵活调整影响范围

  • 信息瓶颈：瓶颈维度 m 过小可能限制表达能力

四、Prefix Tuning（前缀微调）

4.1 核心思想

Prefix Tuning 不修改网络权重，而是在每个 Transformer 层的注意力键（Key）和值（Value）前添加可训练的前缀向量。这些前缀向量作为"软提示"（Soft Prompt），引导模型生成任务特定的输出。

4.2 架构设计

xxxxxxxxxx
标准注意力机制：
  Q = X × W_Q, K = X × W_K, V = X × W_V
  Attention(Q, K, V) = softmax(QK^T/√d) × V


Prefix Tuning：
  K = [P_K; X × W_K]  # 前缀键 + 原始键
  V = [P_V; X × W_V]  # 前缀值 + 原始值
  Attention(Q, K, V) = softmax(Q[P_K;K]^T/√d) × [P_V;V]

其中 P_K 和 P_V 是可训练的前缀参数，维度为 [prefix_length, d]。

4.3 重参数化技巧

直接优化前缀参数效果不佳，Prefix Tuning 引入重参数化：

xxxxxxxxxx
P_K = MLP(P'_K)  # 通过小型 MLP 生成实际前缀
P_V = MLP(P'_V)

  • P'K 和 P'V 是低维可训练参数

  • MLP 在训练后丢弃，仅保存生成的 P_K 和 P_V

  • 目的：稳定训练，避免前缀参数直接优化时的性能下降

4.4 与 Prompt Tuning 的区别

4.5 P-Tuning v2

Prefix Tuning 的改进版本，主要优化：

  • 深层提示：不仅在 K、V 前添加前缀，还在每层都添加可训练的提示向量

  • 多任务共享：不同任务共享部分提示参数，仅任务特定部分独立

  • 去除重参数化：直接使用可训练参数，简化实现

  • 更好的 NLU 性能：在分类、抽取等 NLU 任务上效果优于原始 Prefix Tuning

六、2026 年实践指南

6.1 推荐配置

6.2 关键注意事项

  1. 学习率：PEFT 方法的学习率通常比全参数微调高 5~10 倍（LoRA 常用 1e-4 ~ 2e-4）

  2. 训练轮数：PEFT 通常 1~3 个 epoch 即可，避免过拟合

  3. 数据质量：PEFT 对数据质量更敏感，低质量数据容易过拟合到适配器

  4. 基座选择：PEFT 效果高度依赖基座模型质量，基座能力弱则 PEFT 提升有限

  5. 评估指标：应同时监控训练集和验证集指标，防止适配器过拟合

6.3 组合使用

实践中常将多种 PEFT 方法组合：

  • LoRA + Prefix Tuning：LoRA 更新权重，Prefix Tuning 引导注意力，互补增强

  • Adapter + LoRA：Adapter 处理任务特定变换，LoRA 微调注意力机制

  • QLoRA + DoRA：量化基座 + 分解式低秩更新，资源受限下的最佳效果方案

七、总结

参数高效微调的本质是在"表达能力"与"资源效率"之间寻找最优平衡点。LoRA 凭借其简洁性、高效性和零推理开销，已成为 2026 年最广泛采用的 PEFT 方法。而 Adapter 和 Prefix Tuning 在特定场景（多任务切换、NLU 任务）中仍具有不可替代的价值。理解各方法的核心机制和适用边界，是选择最优微调策略的关键。
