1. 偏见与公平性概述

1.1 偏见的定义

大语言模型从互联网海量数据中习得人类语言，同时也继承了人类社会的刻板印象和偏见。这种算法偏见如果不加干预，将在自动化决策中放大社会不公。

偏见（Bias）：模型输出中对特定群体（基于性别、种族、年龄、宗教等敏感属性）产生系统性偏差或歧视性结果的现象。

公平性（Fairness）：模型在不同人口统计学群体上表现一致，不因敏感属性而产生系统性差异。

- 用户交互反馈循环放大既有偏见
- 上下文和提示工程可能触发或放大偏见

2. 数据偏见

2.1 训练数据中的偏见

大模型的预训练数据来自互联网，不可避免地包含：

  • 性别刻板印象："护士"与"女性"、"工程师"与"男性"的强关联

  • 种族偏见：某些种族与负面属性的共现频率更高

  • 地域偏见：英语语料占主导，非西方文化视角缺失

  • 时代偏见：数据反映特定历史时期的社会观念

  • 社会经济偏见：高收入群体的语言和观点过度代表

2.2 数据采样偏差

2.3 标注偏见

人类标注员的主观判断会引入偏见：

  • 标注员背景偏见：标注员的性别、文化、教育背景影响判断

  • 指令模糊性：标注指南不明确导致标注不一致

  • 疲劳效应：长时间标注导致质量下降和偏见放大

  • 社会期望偏差：标注员倾向于给出"政治正确"的标注

3. 算法公平性

3.1 词嵌入中的偏见

词嵌入（Word Embeddings）是偏见最早被发现的层面：

经典发现：

xxxxxxxxxx
word2vec中：
"man" - "woman" ≈ "king" - "queen"（合理）
"man" - "woman" ≈ "computer programmer" - "homemaker"（偏见）
"father" - "mother" ≈ "doctor" - "nurse"（偏见）

WEAT测试（Word Embedding Association Test）：

xxxxxxxxxx
# 核心思想：测量目标词与属性词之间的关联差异
# 例如：测量"程序员"与"男性/女性"的关联强度差异


def weat_test(target_words, attribute_words_1, attribute_words_2, embeddings):
    target_assoc_1 = mean([cos_sim(w, a) for w in target_words for a in attribute_words_1])
    target_assoc_2 = mean([cos_sim(w, a) for w in target_words for a in attribute_words_2])
    return target_assoc_1 - target_assoc_2

3.2 模型输出中的偏见

生成任务中的偏见：

  • 职业推荐：对"女性"用户推荐"护士"、"教师"，对"男性"推荐"工程师"、"CEO"

  • 角色描述："医生"默认用"he"，"护士"默认用"she"

  • 能力评估：对特定群体的能力评价系统性偏低

分类任务中的偏见：

  • 情感分析：对特定方言或语言风格的文本给出更负面评价

  • 毒性检测：对特定群体的言论误判率更高

3.4 算法公平性的数学定义

群体公平性：

xxxxxxxxxx
P(Ŷ = 1 | A = 0) = P(Ŷ = 1 | A = 1)


其中：
- Ŷ 是模型预测
- A 是敏感属性（如性别、种族）
- 等式表示不同群体获得正向预测的概率相等

机会均等：

xxxxxxxxxx
P(Ŷ = 1 | Y = 1, A = 0) = P(Ŷ = 1 | Y = 1, A = 1)


其中：
- Y 是真实标签
- 等式表示在真正符合条件的个体中，各群体被正确预测的概率相等

反事实公平性：

xxxxxxxxxx
P(Ŷ_{A←0} = y | X = x, A = 0) = P(Ŷ_{A←1} = y | X = x, A = 0)


表示：如果将个体的敏感属性从0改为1，预测结果不应改变

4.3 In-training 去偏

对抗性去偏（Adversarial Debiasing）：

xxxxxxxxxx
训练一个对抗网络同时执行两个任务：
1. 主任务：预测目标变量（如职业分类）
2. 对抗任务：预测敏感属性（如性别）


通过梯度反转层（Gradient Reversal Layer）：
- 主网络最小化主任务损失
- 对抗网络最大化敏感属性预测损失
- 最终主网络学到的表示与敏感属性无关

公平性约束优化：

xxxxxxxxxx
# 在损失函数中添加公平性正则项
total_loss = prediction_loss + λ * fairness_penalty


# 公平性惩罚项可以是：
# - 群体间预测差异的L2范数
# - 机会均等违反程度
# - 校准误差

Dropout正则化去偏：

xxxxxxxxxx
中断注意力机制中词语之间的关联，
减少性别化相关性，降低刻板印象的强化。

公平知识蒸馏：

xxxxxxxxxx
使用反事实角色反转（counterfactual role reversal）
训练公平的知识蒸馏方法：
1. 生成反事实样本（如将"he"替换为"she"）
2. 确保教师模型对原始和反事实样本给出一致的概率分布
3. 用这些公平的概率指导学生模型训练

4.4 Intra-processing 去偏

投影法去偏（Hard Debiasing）：

xxxxxxxxxx
# 子空间投影法核心思想：
# 1. 定义偏见方向（如性别方向）
# 2. 将词向量投影到与偏见方向正交的子空间
# 3. 保留语义信息，消除偏见关联


def hard_debias(embedding, bias_direction):
    # 计算在偏见方向上的投影
    projection = np.dot(embedding, bias_direction) * bias_direction
    # 去除偏见分量
    debiased = embedding - projection
    return debiased

迭代梯度投影（IGBP）：

xxxxxxxxxx
迭代训练一个探测分类器来预测敏感属性，
使用损失函数的梯度指导表示投影到超曲面，
实现非线性编码的偏见去除。

5.4 评估注意事项

  • 多维度评估：单一指标无法全面反映公平性，需综合多个指标

  • 交叉性评估：考虑多重敏感属性的交叉影响（如黑人女性）

  • 上下文敏感性：公平性评估需考虑具体应用场景

  • 人类判断补充：自动化指标无法完全替代人类对偏见的判断

  • 避免评估偏见：评估标准本身不应引入新的偏见
