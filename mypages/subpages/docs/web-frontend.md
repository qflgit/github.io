# Web 前端技能

## 核心能力

- **现代 CSS**：掌握 Flexbox、Grid、容器查询和 CSS 变量
- **响应式设计**：移动端优先的适配策略与断点管理
- **交互体验**：流畅动画、微交互和可访问性设计

## 技术栈

| 技术 | 用途 |
|------|------|
| Tailwind CSS | 实用优先的原子类框架 |
| CSS Grid | 二维复杂布局 |
| CSS Houdini | 自定义绘制与布局 API |
| View Transitions | 页面切换动画 |

## 设计原则

1. 内容优先，渐进增强
2. 性能预算控制，首屏加载 < 1.5s
3. 无障碍设计，WCAG 2.1 AA 标准
4. 暗色模式与系统偏好同步
