# Transformer 核心机制详解

本文深入解析 Transformer 架构中的三大核心组件：**自注意力机制（Self-Attention）**、**多头注意力（Multi-Head Attention）** 和 **位置编码（Positional Encoding）**。这些机制共同构成了现代大语言模型（如 GPT、BERT）的基础。

---

## 一、自注意力机制（Self-Attention）

### 1.1 核心思想

自注意力机制的核心目标是：**让序列中的每个词能够"看到"序列中所有其他词，并根据相关性动态地加权融合它们的信息**。

传统 RNN/LSTM 是逐步顺序处理序列的，后面的词只能依赖前面的信息。而自注意力机制打破了这一限制——序列中的任意两个位置都可以直接建立联系，无论它们相距多远。

### 1.2 数学原理

自注意力通过三个投影矩阵将输入向量映射为 **Query（查询）**、**Key（键）** 和 **Value（值）** 三个向量：

```
Q = X · W_Q
K = X · W_K
V = X · W_V
```

其中：
- **X** 是输入序列的嵌入矩阵（形状：`[seq_len, d_model]`）
- **W_Q, W_K, W_V** 是可学习的投影矩阵（形状：`[d_model, d_k]`）
- **Q, K, V** 分别是查询、键、值矩阵

### 1.3 注意力分数计算

自注意力的输出通过以下公式计算：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) · V
```

计算步骤分解：

**第一步：计算相似度分数（Score）**

```
Score = Q · K^T
```

这一步计算每个 Query 与所有 Key 的点积，得到一个 `seq_len × seq_len` 的相似度矩阵。分数越高，表示两个位置之间的语义关联越强。

**第二步：缩放（Scale）**

```
Scaled Score = Score / √d_k
```

除以 `√d_k` 的目的是防止点积结果过大，导致 softmax 函数的梯度变得非常小（梯度消失问题）。当维度 `d_k` 很大时，点积的方差会随之增大，缩放操作可以稳定训练。

**第三步：Softmax 归一化**

```
Attention Weights = softmax(Scaled Score)
```

Softmax 将分数转换为概率分布，每一行的和为 1。这些权重表示：当前位置应该"关注"其他位置的程度。

**第四步：加权求和**

```
Output = Attention Weights · V
```

用注意力权重对 Value 向量进行加权求和，得到最终的输出表示。

### 1.4 直观理解

假设输入句子是："The cat sat on the mat"

当模型处理 "cat" 这个词时：
- "cat" 的 Query 向量与 "The"、"cat"、"sat"、"on"、"the"、"mat" 的 Key 向量分别计算相似度
- 模型会发现 "cat" 与 "sat"、"mat" 的关联度较高（因为猫坐在垫子上）
- 最终 "cat" 的输出表示会融合更多来自 "sat" 和 "mat" 的信息

### 1.5 掩码自注意力（Masked Self-Attention）

在解码器（如 GPT）中，为了防止模型在生成当前词时"偷看"未来的词，会使用掩码：

```
Masked Score = Score + Mask
Mask[i][j] = -∞  (当 j > i 时，即未来位置)
Mask[i][j] = 0   (当 j ≤ i 时，即当前及过去位置)
```

这样，softmax 后未来位置的权重会变为 0，确保自回归生成。

## 二、多头注意力（Multi-Head Attention）

### 2.1 核心思想

**多头注意力的核心思想是：让模型同时从多个不同的"视角"或"子空间"去关注输入序列。**

单一的自注意力机制可能只捕捉到某一类关系（如语法关系）。多头注意力通过多组独立的 Q/K/V 投影，让模型能够同时捕捉不同类型的依赖关系：
- 一个头可能关注主谓关系
- 另一个头可能关注指代关系
- 还有一个头可能关注语义相似性

### 2.2 数学原理

多头注意力将输入投影到 `h` 个不同的子空间中，每个子空间独立执行自注意力：

```
MultiHead(Q, K, V) = Concat(head_1, head_2, ..., head_h) · W_O

where head_i = Attention(Q · W_Q^i, K · W_K^i, V · W_V^i)
```

其中：
- **h** 是头的数量（常见配置：8、12、16）
- **W_Q^i, W_K^i, W_V^i** 是第 i 个头的投影矩阵（形状：`[d_model, d_k]`）
- **d_k = d_model / h**，每个头的维度
- **W_O** 是输出投影矩阵（形状：`[d_model, d_model]`）

### 2.3 计算流程详解

假设 `d_model = 512`，`h = 8`，则每个头的维度 `d_k = 64`：

**步骤 1：多头投影**

输入 X 分别与 8 组 Q/K/V 投影矩阵相乘，得到 8 组 Q_i, K_i, V_i。

**步骤 2：独立注意力计算**

每个头独立执行缩放点积注意力：

```
head_i = softmax(Q_i · K_i^T / √64) · V_i
```

每个 head_i 的形状为 `[seq_len, 64]`。

**步骤 3：拼接与线性变换**

将 8 个头的输出拼接在一起：

```
Concat(head_1, ..., head_8) → [seq_len, 512]
```

然后通过输出投影矩阵 W_O 进行线性变换：

```
Output = Concat(...) · W_O → [seq_len, 512]
```

### 2.4 为什么多头有效？

1. **多视角表示**：不同头可以学习不同的语义关系
2. **增强表达能力**：将高维空间划分为多个子空间，降低每个子空间的学习难度
3. **计算效率**：每个头的维度降低，总计算量与单头注意力相近

### 2.5 可视化理解

```
输入 X ──┬──→ [W_Q^1, W_K^1, W_V^1] ──→ head_1 ──┐
         ├──→ [W_Q^2, W_K^2, W_V^2] ──→ head_2 ──┤
         ├──→ [W_Q^3, W_K^3, W_V^3] ──→ head_3 ──┤
         ...                                      ├──→ Concat ──→ W_O ──→ Output
         ├──→ [W_Q^h, W_K^h, W_V^h] ──→ head_h ──┘
```

## 三、位置编码（Positional Encoding）

### 3.1 为什么需要位置编码？

**自注意力机制本身是完全"位置无关"的（Permutation Invariant）。**

也就是说，如果将输入序列的顺序打乱，自注意力的输出结果只会跟着置换，而**不会感知到顺序的变化**。例如：
- "猫追老鼠" 和 "老鼠追猫"
- 对自注意力来说，如果不加入位置信息，这两个句子的处理方式是一样的

因此，必须显式地将位置信息注入模型。

### 3.2 正弦/余弦位置编码（Sinusoidal）

Transformer 原始论文提出的位置编码使用不同频率的正弦和余弦函数：

```
PE(pos, 2i)   = sin(pos / 10000^(2i / d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))
```

其中：
- **pos**：词在序列中的位置（0, 1, 2, ...）
- **i**：维度索引
- **d_model**：模型的维度

### 3.3 设计原理

**为什么使用正弦/余弦函数？**

1. **唯一性**：每个位置 pos 都有唯一的编码向量
2. **相对位置感知**：对于固定的偏移量 k，`PE(pos+k)` 可以表示为 `PE(pos)` 的线性函数

   利用三角恒等式：
   ```
   sin(a+b) = sin(a)cos(b) + cos(a)sin(b)
   cos(a+b) = cos(a)cos(b) - sin(a)sin(b)
   ```

   这意味着模型可以通过学习来理解相对位置关系。

3. **外推性**：正弦函数是周期性的，理论上可以泛化到训练时未见过的更长序列

4. **值域有界**：输出值始终在 [-1, 1] 之间，与词嵌入的值域匹配

### 3.4 可视化理解

不同维度 i 对应不同频率的波形：

- **低维度（i 较小）**：波长较长，变化缓慢 → 捕捉远距离的位置关系
- **高维度（i 较大）**：波长较短，变化迅速 → 捕捉精细的位置差异

```
维度 0:  sin(pos / 10000^0)    → 波长 ≈ 2π，变化最慢
维度 1:  cos(pos / 10000^0)    → 同上
维度 2:  sin(pos / 10000^(2/512)) → 波长稍短
...
维度 510: sin(pos / 10000^(510/512)) → 波长极短，变化最快
维度 511: cos(pos / 10000^(510/512)) → 同上
```

### 3.5 可学习的位置编码（Learned Positional Embedding）

后来的模型（如 BERT、GPT）采用了另一种方案：**将位置编码作为可学习的参数**：

```
X = WordEmbedding + PositionalEmbedding
```

其中 PositionalEmbedding 是一个可学习的查找表：`[max_seq_len, d_model]`

**优缺点对比：**

| 特性 | 正弦编码 | 可学习编码 |
|------|----------|------------|
| 外推性 | 好（可泛化到更长序列） | 差（受限于 max_seq_len） |
| 灵活性 | 固定函数 | 可自适应优化 |
| 参数量 | 无额外参数 | 需要额外参数 |
| 相对位置 | 天然支持 | 需要额外设计 |

### 3.6 相对位置编码（Relative Positional Encoding）

更先进的方案（如 Transformer-XL、T5、DeBERTa）引入了**相对位置编码**：

不再为每个绝对位置分配编码，而是为**位置之间的相对距离**分配编码：

```
Attention Score = Q · K^T + Q · R^T
```

其中 R 是相对位置编码矩阵。这种方法更好地捕捉了序列中的相对顺序关系。

### 3.7 RoPE（旋转位置编码）

现代大模型（如 LLaMA、GPT-4）广泛使用的 **Rotary Position Embedding（RoPE）**：

核心思想：通过旋转矩阵将位置信息编码到 Q 和 K 向量中：

```
RoPE(x, pos) = x · R(pos)

where R(pos) 是一个旋转矩阵
```

对于二维情况：
```
R(pos) = [ cos(pos·θ), -sin(pos·θ) ]
         [ sin(pos·θ),  cos(pos·θ) ]
```

**RoPE 的优势：**
- 保持内积的相对位置特性：`RoPE(q, m) · RoPE(k, n) = f(m-n)`
- 与注意力机制天然兼容
- 支持长序列外推（通过调整频率基数）

## 四、三者协同工作原理

### 4.1 完整流程

```
输入序列: ["The", "cat", "sat", "on", "the", "mat"]

         ↓
    Word Embedding
         ↓
    + Positional Encoding  ← 注入位置信息
         ↓
    ┌─────────────────────────────────────┐
    │         Multi-Head Attention          │
    │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
    │  │Head1│ │Head2│ │Head3│ │Head4│   │ ← 多视角注意力
    │  └─────┘ └─────┘ └─────┘ └─────┘   │
    │              Concat                 │
    │              W_O                    │
    └─────────────────────────────────────┘
         ↓
    Add & LayerNorm (残差连接 + 层归一化)
         ↓
    Feed-Forward Network
         ↓
    Add & LayerNorm
         ↓
    输出: 富含上下文信息的表示
```

### 4.2 关键交互

1. **位置编码 + 自注意力**：位置编码让每个词携带"我在第几个位置"的信息，自注意力在此基础上计算语义关联

2. **多头 + 自注意力**：多个头分别关注不同类型的关系，丰富了表示能力

3. **残差连接**：`Output = LayerNorm(X + Attention(X))`，确保梯度可以顺畅回流，支持深层网络训练

## 五、总结

| 机制 | 核心功能 | 关键公式/思想 |
|------|----------|---------------|
| **自注意力** | 建立序列中任意两个位置的直接联系 | `softmax(QK^T/√d_k)·V` |
| **多头注意力** | 多视角并行关注，增强表达能力 | h 组独立 Q/K/V + Concat |
| **位置编码** | 注入顺序信息，打破位置无关性 | 正弦/可学习/RoPE |

这三者的组合使 Transformer 能够：
- **并行处理**整个序列（不像 RNN 必须串行）
- **捕捉长距离依赖**（任意两个位置直接相连）
- **理解复杂语义关系**（多头多视角）
- **感知序列顺序**（位置编码）

正是这些特性，使得 Transformer 成为现代 NLP 和视觉模型的基石。
