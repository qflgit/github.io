1. MCP 概述

Model Context Protocol (MCP) 是一种开放标准协议，用于定义应用程序如何与大型语言模型 (LLM) 共享上下文。MCP 提供了一种标准化的方式，将 AI 模型连接到不同的数据源和工具，使其能够更有效地协同工作。

通过 MCP，AI 编程助手可以：

  • 直接访问数据库、API 文档和内部知识库

  • 执行终端命令或运行配置

  • 与第三方服务（如 GitHub、Slack、Notion）交互

  • 减少开发者在不同信息源之间切换的上下文切换成本

2. Cursor MCP 配置

2.1 配置文件位置

Cursor 支持两种级别的 MCP 配置：

2.2 配置步骤

  1. 打开 Cursor 设置

    • 启动 Cursor，进入 首选项 (Preferences) → Cursor Settings

    • 找到 MCP 选项卡

  2. 添加 MCP 服务器

    • 点击 Add a new global MCP server

    • 首次配置时，Cursor 会提示创建 mcp.json 文件，点击 创建

  3. 编辑 mcp.json 文件

    以下是一个完整的 Cursor MCP 配置示例：

    {
      "mcpServers": {
        "playwright": {
          "command": "npx",
          "args": ["-y", "@playwright/mcp@latest"]
        },
        "github": {
          "command": "npx",
          "args": ["-y", "@modelcontextprotocol/server-github"],
          "env": {
            "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxxxxxxxxxxx"
          }
        },
        "puppeteer": {
          "command": "npx",
          "args": ["-y", "@modelcontextprotocol/server-puppeteer"]
        },
        "amap": {
          "url": "https://mcp.amap.com/sse?key=您的高德地图Key"
        }
      }
    }

  4. 验证服务状态

    • 回到 MCP 设置界面

    • 服务名称前显示 绿色对勾 ✅ 表示成功加载

    • 若未显示，点击 刷新 (Refresh) 按钮

2.3 Cursor 配置要点

  • 命令类型 (stdio)：使用 command + args 格式，适用于本地运行的 MCP 服务器

  • URL 类型 (sse)：使用 url 字段，适用于远程 SSE 服务（如高德地图 MCP）

  • 环境变量：在 env 块中定义 API 密钥等敏感信息

  • 版本要求：Cursor 0.46.8 或更高版本支持 MCP

3. Claude Code MCP 配置

3.1 配置文件位置

Claude Code 使用 ~/.claude.json 作为主配置文件：

3.2 配置步骤

  1. 安装 Claude Code CLI

    xxxxxxxxxx
    npm install -g @anthropic/claude-code

    要求 Node.js v20+。

  2. 创建配置目录

    xxxxxxxxxx
    mkdir -p ~/.claude/.taskmaster-global

  3. 编辑 ~/.claude.json 文件

    xxxxxxxxxx
    {
      "mcpServers": {
        "context7": {
          "type": "stdio",
          "command": "npx",
          "args": ["-y", "@upstash/context7-mcp"],
          "env": {}
        },
        "taskmaster-ai": {
          "type": "stdio",
          "command": "npx",
          "args": ["task-master-ai"],
          "env": {}
        },
        "github": {
          "type": "stdio",
          "command": "npx",
          "args": ["-y", "@modelcontextprotocol/server-github"],
          "env": {
            "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxxxxxxxxxxx"
          }
        }
      }
    }

  4. 配置环境变量 在 ~/.bashrc 或 ~/.zshrc 中添加：

    xxxxxxxxxx
    export CLAUDECODE=1
    export CLAUDE_CODE_ENTRYPOINT=cli
    export TASKMASTER_DEFAULT_PROVIDER=claude-code
    export TASKMASTER_GLOBAL_CONFIG=~/.claude/.taskmaster-global/config.json

  5. 重载配置

    xxxxxxxxxx
    claude --reload-config

3.3 Claude Code 特有功能

  • Context7：实时文档查询，在提问时追加 use context7 即可调用

  • TaskMaster AI：项目管理工具，支持 /project-setup、/parse-prd、/next-task 等命令

  • 权限模式：支持 default、acceptEdits、auto、dontAsk、plan 等权限级别

4. Windsurf MCP 配置

4.1 配置文件位置

Windsurf (由 Codeium 提供) 使用以下路径：

4.2 配置步骤

  1. 通过界面安装内置 MCP

    • 打开 Windsurf，点击侧边栏的 Plugins 图标

    • 浏览可用的 MCP 服务器（如 Supabase、Notion）

    • 选择服务器并点击 Install

    • 输入 API 密钥或认证凭据，点击 Save

  2. 手动配置外部 MCP

    • 访问 GitHub MCP 服务器列表或其他 MCP 目录

    • 复制所需服务器的配置

    • 在 Windsurf 中进入 Plugins → Manage plugins → View raw config

    • 粘贴配置并添加 API 密钥

  3. 直接编辑 mcp_config.json

    xxxxxxxxxx
    {
      "mcpServers": {
        "supabase": {
          "command": "npx",
          "args": ["-y", "@supabase/mcp-server-postgrest", "--apiUrl", "https://your-project.supabase.co/rest/v1", "--apiKey", "your-anon-key", "--schema", "public"]
        },
        "brave-search": {
          "command": "npx",
          "args": ["-y", "@modelcontextprotocol/server-brave-search"],
          "env": {
            "BRAVE_API_KEY": "your_brave_api_key"
          }
        },
        "slack": {
          "command": "npx",
          "args": ["-y", "@modelcontextprotocol/server-slack"],
          "env": {
            "SLACK_BOT_TOKEN": "xoxb-your-token",
            "SLACK_TEAM_ID": "your-team-id"
          }
        },
        "airflow": {
          "command": "airflow",
          "args": [],
          "env": {
            "AIRFLOW_HOST": "http://localhost:8080",
            "AIRFLOW_USERNAME": "admin",
            "AIRFLOW_PASSWORD": "admin_password",
            "AIRFLOW_READ_ONLY": "true"
          }
        }
      }
    }

  4. 重启 Windsurf

    • 完全退出并重新启动 Windsurf Editor，使配置生效

4.3 Windsurf 配置要点

  • 内置服务器：Windsurf 提供预配置的 MCP 服务器，可通过 GUI 一键安装

  • 外部服务器：需手动编辑 mcp_config.json 文件

  • 环境变量：必须在 env 块中显式定义，MCP 服务器不会继承宿主环境变量

  • 验证方式：在 Cascade 聊天中查看工具列表（Hammer 图标）确认加载成功

6. 常见问题排查

6.1 服务未显示 / 工具未加载

症状：MCP 设置界面无服务列表，或 Cascade/Agent 中 Hammer 图标缺失

解决方案：

  1. 检查 mcp.json / mcp_config.json 的 JSON 语法是否正确

  2. 确认 command（如 npx、node、python）已在系统 PATH 中

  3. 检查 IDE 日志中的 MCP 连接错误信息

  4. 重启 IDE 使配置生效

6.2 认证失败 / 权限被拒绝

症状：API 调用返回 401/403 错误

解决方案：

  1. 确认 env 块正确定义在服务器配置内部

  2. 检查 API 密钥是否有效且未过期

  3. 修改环境变量后必须重启 IDE

  4. 确保 MCP 服务器未继承宿主环境变量（需显式定义）

6.3 Node.js / 依赖问题

症状：命令执行失败，提示找不到模块

解决方案：

  1. 确保 Node.js >= v18.0.0（推荐 v20+）

  2. 使用 npx -y 自动安装缺失包

  3. 对于本地构建的 MCP，先执行 npm install && npm run build

  4. 检查 Docker 是否已安装（针对需要容器化的 MCP）
