图像分割技术详解：语义分割、实例分割与 SAM 大模型

一、概述

图像分割是计算机视觉的核心任务，旨在将图像划分为具有语义意义的区域。从像素级分类到实例级区分，再到"分割一切"的基础模型，分割技术经历了从专用到通用、从封闭到开放的范式转变。本文系统介绍语义分割、实例分割、全景分割三大经典任务，以及 Segment Anything Model（SAM）系列大模型如何重新定义分割技术的边界。

二、分割任务分类

2.1 三大核心任务

图像分割
├── 语义分割（Semantic Segmentation）
│   └── 每个像素 → 类别标签（不区分实例）
│
├── 实例分割（Instance Segmentation）
│   └── 每个像素 → 类别 + 实例 ID（区分个体）
│
└── 全景分割（Panoptic Segmentation）
    └── 统一语义分割 + 实例分割（可计数"事物"+ 不可计数"物质"）

2.2 任务对比

三、语义分割

3.1 核心思想

语义分割为图像中的每个像素分配一个类别标签，所有同类别的像素被视为同一实体，不区分具体实例。例如，两辆车相邻停放，语义分割会将两车像素都标记为"车辆"，但不区分"车 A"和"车 B"。

3.2 经典架构

3.2.1 FCN（Fully Convolutional Network）

FCN 是首个端到端语义分割网络，核心创新：

  • 将全连接层替换为卷积层，实现任意尺寸输入

  • 使用反卷积（Deconvolution）进行上采样

  • 跳跃连接融合深层语义和浅层细节

xxxxxxxxxx
输入图像
    ↓
Conv Block 1 → 特征图 1 (高分辨率，低语义)
    ↓
Conv Block 2 → 特征图 2
    ↓
Conv Block 3 → 特征图 3
    ↓
Conv Block 4 → 特征图 4
    ↓
Conv Block 5 → 特征图 5 (低分辨率，高语义)
    ↓
FC6/FC7 (卷积化)
    ↓
反卷积上采样 ×32
    ↓
像素级分类输出

3.2.2 U-Net

U-Net 专为医学图像分割设计，采用对称的编码器-解码器结构：

​x
编码器（下采样）                    解码器（上采样）
Conv → Conv → MaxPool ─────────────→ ConvTranspose → Conv → Conv
    ↓                                    ↑
Conv → Conv → MaxPool ─────────────→ ConvTranspose → Conv → Conv
    ↓                                    ↑
Conv → Conv → MaxPool ─────────────→ ConvTranspose → Conv → Conv
    ↓                                    ↑
Conv → Conv → MaxPool ─────────────→ ConvTranspose → Conv → Conv
    ↓                                    ↑
Bottleneck ─────────────────────────────┘


跳跃连接：将编码器特征直接连接到解码器，保留细节信息

特点：

  • 编码器提取多尺度特征

  • 解码器恢复空间分辨率

  • 跳跃连接融合高低层特征

  • 在医学影像和小样本场景表现优异

3.2.3 DeepLab 系列

DeepLab 引入空洞卷积（Atrous Convolution）解决分辨率下降问题：

xxxxxxxxxx
标准卷积：感受野随层数线性增长，分辨率指数下降
空洞卷积：通过空洞率（dilation rate）扩大感受野，不损失分辨率


DeepLab v3+ 架构：
- 编码器：ResNet/Xception + 空洞空间金字塔池化（ASPP）
- ASPP：多尺度特征提取（空洞率 6, 12, 18）
- 解码器：双线性上采样 + 低层特征融合

四、实例分割

4.1 核心思想

实例分割在语义分割的基础上，进一步区分同一类别的不同实例。每辆车、每个人都被赋予独立的实例 ID，支持计数、跟踪和个体分析。

4.2 Mask R-CNN

Mask R-CNN 是实例分割的里程碑模型，在 Faster R-CNN 基础上增加掩码分支：

xxxxxxxxxx
输入图像
    ↓
Backbone（ResNet + FPN）
    ↓
RPN（Region Proposal Network）→ 候选框
    ↓
RoI Align（对齐特征）
    ↓
┌─────────────┬─────────────┬─────────────┐
│  分类分支    │  回归分支    │  掩码分支    │
│  预测类别    │  精修边界框  │  预测分割掩码 │
│  (FC 层)    │  (FC 层)    │  (FCN)      │
└─────────────┴─────────────┴─────────────┘

关键创新：

  • RoI Align：使用双线性插值替代 RoI Pooling，避免量化误差

  • 掩码分支：全卷积网络预测每个 RoI 的二值掩码

  • 多任务损失：L = L_cls + L_box + L_mask

五、全景分割

5.1 核心思想

全景分割统一处理两类视觉概念：

  • "事物"（Things）：可计数的离散对象（人、车、椅子），需要实例 ID

  • "物质"（Stuff）：不可计数的连续区域（天空、道路、草地），只需类别标签

5.2 传统方法

早期方法分别执行语义分割和实例分割，然后融合结果：

xxxxxxxxxx
输入图像
    ├──→ FCN → 语义分割图（所有像素类别）
    └──→ Mask R-CNN → 实例掩码（仅"事物"类）
              ↓
         Panoptic Fusion Module
              ↓
         解决冲突（重叠像素归属）
              ↓
         全景分割输出

5.4 评估指标

PQ（Panoptic Quality）：

xxxxxxxxxx
PQ = Σ PQ_i / N_classes
PQ_i = (IoU_i / (1 + FP_i + FN_i)) × RQ_i


其中:
- RQ（Recognition Quality）= TP / (TP + 0.5×FP + 0.5×FN)
- SQ（Segmentation Quality）= 匹配掩码的平均 IoU
- PQ = RQ × SQ

六、SAM（Segment Anything Model）大模型

6.1 核心思想

SAM 是 Meta AI 于 2023 年发布的可提示分割基础模型，其设计目标是"分割一切"——给定任意提示（点、框、掩码、文本），模型能够零样本（zero-shot）分割图像中的任意对象。

  • 每图像只运行一次，后续提示复用该嵌入

  • 歧义处理：单个提示预测 3 个掩码（整体、部分、子部分）

6.4 数据引擎

SAM 的强大能力源于 SA-1B 数据集（11M 图像，1.1B 掩码），通过三阶段数据引擎构建：

xxxxxxxxxx
阶段 1: 模型辅助人工标注
  - 标注员使用交互式工具（SAM 辅助）标注掩码
  - 模型改进 → 标注效率提升（从 34 秒/掩码降至 14 秒）


阶段 2: 半自动标注
  - SAM 自动生成高置信度掩码
  - 标注员专注于剩余未标注对象
  - 提升掩码多样性


阶段 3: 全自动标注
  - 32×32 网格点作为提示
  - 平均每图 100 个高质量掩码
  - 歧义感知预测 + NMS 过滤

6.5 SAM 版本演进

6.6 SAM 2：视频分割

SAM 2 引入流式记忆机制，实现视频中的对象跟踪：

xxxxxxxxxx
视频帧序列
    ↓
图像编码器（每帧）
    ↓
记忆编码器 → 记忆库（存储过去帧信息）
    ↓
记忆注意力 → 当前帧与记忆交互
    ↓
掩码解码器 → 当前帧分割结果
    ↓
对象指针 → 跨帧身份保持

关键特性：

  • 流式处理：逐帧处理，无需预加载整个视频

  • 记忆库：存储对象特征，支持长程跟踪

  • 对象指针：维护跨帧对象身份一致性

6.7 SAM 3：概念分割

SAM 3 引入 Promptable Concept Segmentation（PCS），支持文本和示例图像提示：

xxxxxxxxxx
文本提示: "yellow school bus"
    ↓
CLIP 文本编码器
    ↓
文本嵌入 → 图像级检测器 → 存在性头（Presence Head）
    ↓
检测所有匹配概念的实例
    ↓
掩码解码器 → 分割掩码 + 唯一身份 ID

核心创新：

  • 存在性头（Presence Head）：解耦识别与定位，提升检测精度

  • 记忆跟踪器：视频中的概念实例跟踪

  • 开放词汇：无需训练即可分割新概念

八、2026 年趋势

九、总结

图像分割技术正从"任务专用模型"向"通用基础模型"演进。SAM 系列通过可提示的交互范式，将分割能力从封闭的训练类别扩展到开放的视觉世界。2026 年的分割技术已不再是简单的像素分类，而是融合了语义理解、时序推理、多模态交互的智能视觉感知系统，为自动驾驶、医学影像、机器人视觉、内容创作等领域提供了强大的基础能力。
