概述

云成本优化是现代AI/ML基础设施管理的核心挑战。随着模型规模扩大和推理需求增长，计算成本呈指数级上升。本策略文档系统性地介绍三大核心优化方向：自动扩缩容、Spot实例利用以及推理成本精细化分析。

自动扩缩容策略

1. 水平自动扩缩容（HPA）

水平Pod自动扩缩容根据CPU、内存或自定义指标动态调整Pod副本数量。

扩缩容行为优化

扩容策略：

  • 快速扩容（Fast Scale-Up）：应对突发流量，60秒内翻倍扩容

  • 渐进扩容：避免资源震荡，每次扩容不超过当前实例数的50%

缩容策略：

  • 保守缩容（Conservative Scale-Down）：缩容前等待5分钟稳定期

  • 冷却窗口：防止频繁扩缩容导致的资源抖动

2. 垂直自动扩缩容（VPA）

VPA根据实际资源使用情况调整Pod的资源请求（requests）和限制（limits）。

import signal
import sys
import os
from datetime import datetime


class SpotInstanceHandler:
    def __init__(self, checkpoint_dir="/mnt/checkpoints"):
        self.checkpoint_dir = checkpoint_dir
        self.interrupted = False
        self.setup_handlers()


    def setup_handlers(self):
        # 处理SIGTERM（AWS Spot中断通知）
        signal.signal(signal.SIGTERM, self.handle_interrupt)
        # 处理SIGINT（手动中断）
        signal.signal(signal.SIGINT, self.handle_interrupt)


    def handle_interrupt(self, signum, frame):
        print(f"[{datetime.now()}] 收到中断信号 {signum}，开始保存状态...")
        self.interrupted = True
        self.save_checkpoint()
        sys.exit(0)


    def save_checkpoint(self):
        checkpoint_path = os.path.join(
            self.checkpoint_dir, 
            f"checkpoint_{datetime.now().strftime('%Y%m%d_%H%M%S')}.pt"
        )
        # 保存模型状态、优化器状态、训练进度
        torch.save({
            'model_state_dict': model.state_dict(),
            'optimizer_state_dict': optimizer.state_dict(),
            'epoch': current_epoch,
            'step': global_step,
            'interrupted': True
        }, checkpoint_path)
        print(f"检查点已保存至: {checkpoint_path}")


    def resume_from_checkpoint(self, checkpoint_path):
        checkpoint = torch.load(checkpoint_path)
        model.load_state_dict(checkpoint['model_state_dict'])
        optimizer.load_state_dict(checkpoint['optimizer_state_dict'])
        return checkpoint['epoch'], checkpoint['step']

推理成本分析

1. 推理成本构成

成本分解模型

xxxxxxxxxx
总推理成本 = 计算成本 + 存储成本 + 网络成本 + 管理成本


计算成本 = GPU实例费用 x 运行时间 x 利用率
存储成本 = 模型权重存储 + 输入/输出缓存 + 日志存储
网络成本 = 入站流量 + 出站流量 + 跨区域传输
管理成本 = 负载均衡 + 监控 + 运维人力

# 动态批处理示例
class DynamicBatcher:
    def __init__(self, max_batch_size=8, max_wait_ms=50):
        self.max_batch_size = max_batch_size
        self.max_wait_ms = max_wait_ms
        self.request_queue = []


    async def process_batch(self):
        batch = []
        start_time = time.time()


        while (len(batch) < self.max_batch_size and 
               (time.time() - start_time) * 1000 < self.max_wait_ms):
            if self.request_queue:
                batch.append(self.request_queue.pop(0))
            await asyncio.sleep(0.001)


        if batch:
            # 合并输入进行批量推理
            inputs = self.collate_batch(batch)
            outputs = model(inputs)
            # 分发结果
            return self.split_outputs(outputs, batch)
        return []

# 模型预热与缓存策略
class ModelCache:
    def __init__(self, cache_size=3):
        self.cache = OrderedDict()
        self.cache_size = cache_size
        self.current_model = None


    def load_model(self, model_name):
        if model_name in self.cache:
            # LRU缓存命中
            self.cache.move_to_end(model_name)
            return self.cache[model_name]


        # 加载新模型
        model = self._load_from_storage(model_name)


        # 缓存淘汰
        if len(self.cache) >= self.cache_size:
            oldest_model = self.cache.popitem(last=False)
            self._unload_model(oldest_model[1])


        self.cache[model_name] = model
        return model


    def _load_from_storage(self, model_name):
        # 从对象存储加载模型

# 关键成本指标计算
class InferenceCostAnalyzer:
    def __init__(self):
        self.gpu_hourly_cost = 2.5  # $/hour for A10G
        self.storage_cost_per_gb = 0.023  # $/GB/month


    def calculate_cost_per_request(self, requests, total_tokens, runtime_hours):
        # 计算单次请求成本
        compute_cost = runtime_hours * self.gpu_hourly_cost
        cost_per_request = compute_cost / requests
        cost_per_token = compute_cost / total_tokens
        return {
            "cost_per_request": cost_per_request,
            "cost_per_1k_tokens": cost_per_token * 1000,
            "gpu_utilization": self.get_gpu_utilization()
        }


    def calculate_savings_opportunity(self, current_config, optimized_config):
        # 计算优化潜力
        current_cost = self.estimate_cost(current_config)
        optimized_cost = self.estimate_cost(optimized_config)
        return {
            "current_monthly_cost": current_cost,
            "optimized_monthly_cost": optimized_cost,
            "monthly_savings": current_cost - optimized_cost,
            "savings_percentage": (current_cost - optimized_cost) / current_cost * 100
        }

实施路线图

第一阶段：基础优化（1-2周）

  • 部署HPA和Cluster Autoscaler

  • 配置基础监控和告警

  • 启用Spot实例用于非关键工作负载

  • 建立成本基线

第二阶段：深度优化（2-4周）

  • 实施动态批处理

  • 部署KEDA事件驱动扩缩容

  • 启用模型量化（INT8/FP16）

  • 建立成本归因体系

第三阶段：智能化优化（1-2月）

  • 实施预测性扩缩容

  • 优化Spot实例混合策略

  • 多模型共享GPU部署

  • 自动化成本优化闭环

第四阶段：持续优化（长期）

  • 定期成本审查（月度/季度）

  • 新优化技术评估与引入

  • 跨团队成本意识培养

  • FinOps实践落地
