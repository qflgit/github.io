YOLO 系列与 DETR 端到端检测架构详解

一、概述

目标检测是计算机视觉的核心任务，旨在识别图像中的目标并定位其边界框。传统方法经历了从两阶段（Faster R-CNN）到单阶段（YOLO）的演进，而 DETR（DEtection TRansformer）的出现标志着端到端检测范式的诞生。2024-2026 年，YOLO 系列持续迭代至 YOLO26，同时 DETR 及其变体（RT-DETR、RF-DETR、DEIM）在实时性和精度上不断突破，两条技术路线正加速融合。

二、YOLO 系列演进

2.1 YOLO 核心思想

YOLO（You Only Look Once）将目标检测视为单次回归问题：输入图像经过单次前向传播，直接输出所有目标的边界框坐标和类别概率。这种"一阶段"设计使其在速度上远超两阶段检测器。

输入图像 [3×H×W]
    ↓
Backbone（特征提取）
    ↓
Neck（特征融合，FPN/PAN）
    ↓
Head（检测头：分类 + 回归）
    ↓
输出: 边界框 [x, y, w, h] + 置信度 + 类别概率

2.3.2 Neck（PANet 改进）

xxxxxxxxxx
自顶向下（上采样 + 融合）: P5 → P4 → P3
    ↓
自底向上（下采样 + 融合）: P3 → P4 → P5
    ↓

2.3.3 Head（解耦头）

xxxxxxxxxx
传统耦合头: 分类和回归共享特征
YOLOv8 解耦头:
  特征 → 分类分支（Cls）→ 类别概率
       → 回归分支（Reg）→ 边界框坐标

Anchor-Free 设计：

  • 直接预测边界框中心点到四条边的距离

  • 无需预设 Anchor 尺寸

  • 自适应不同形状的目标

2.4 YOLOv9：可编程梯度信息（PGI）

YOLOv9 引入 GELAN（Generalized Efficient Layer Aggregation Network）和 PGI：

​x
PGI 辅助分支:
  主分支: 正常前向传播 → 预测

目的:

2.5 YOLOv10：无 NMS 端到端

YOLOv10 的核心突破是消除非极大值抑制（NMS）后处理：

2.5.1 一致双分配策略

xxxxxxxxxx
训练阶段:
  ├── 一对多分配（One-to-Many）: 多个预测框匹配一个 GT，提供丰富监督
  └── 一对一分支（One-to-One）: 仅一个预测框匹配 GT，模拟推理时的唯一性


推理阶段:
  └── 仅使用 One-to-One 分支，直接输出最终检测结果，无需 NMS

2.5.2 效率优化

  • 轻量级分类头：减少计算冗余

  • 空间-通道解耦下采样：减少信息损失

  • 秩引导块设计：根据特征重要性动态分配计算

三、DETR：端到端 Transformer 检测

3.1 核心思想

DETR（DEtection TRansformer）由 Facebook Research（Meta AI）于 2020 年提出，将目标检测重新定义为集合预测问题：

xxxxxxxxxx
传统检测: 密集预测 + 锚框筛选 + NMS 去重
DETR: 图像 → Transformer → 固定数量预测集合 → 二分匹配 → 最终结果

关键创新：

  • 无需锚框（Anchor-Free）

  • 无需 NMS（端到端输出）

  • 全局注意力建模

  • 集合预测 + 二分图匹配

3.2 架构详解

xxxxxxxxxx
输入图像 [3×H×W]
    ↓
Backbone（ResNet-50/101）
    ↓
特征图 [C×H'×W']
    ↓
1×1 Conv 降维 + 展平
    ↓
特征序列 [N×D]  (N = H'×W')
    ↓
┌─────────────────────────────────────────┐
│  Transformer Encoder（自注意力）           │
│  全局特征交互，增强上下文感知               │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Transformer Decoder（交叉注意力）         │
│  Object Queries [M×D] 与编码器特征交互    │
│  M = 100（默认查询数量）                   │
└─────────────────────────────────────────┘
    ↓
预测头（FFN）
    ↓
输出 M 个预测: {类别, 边界框}

3.3 Object Queries（对象查询）

Object Queries 是 DETR 的核心设计：

xxxxxxxxxx
可学习的嵌入向量 [100 × 256]
    ↓
Decoder 中通过交叉注意力与图像特征交互
    ↓
每个 Query 学习检测特定类型的目标
    ↓
最终输出 100 个预测（包含 "无目标" 类别）

特性：

  • 随机初始化，端到端学习

  • 每个 Query 隐式学习空间位置和物体类别

  • 注意力图可视化可解释 Query 行为

3.4 二分图匹配（Bipartite Matching）

DETR 使用匈牙利算法进行预测与 GT 的最优匹配：

xxxxxxxxxx
损失 = L_cls(类别预测, 类别GT) + λ L_box(框预测, 框GT)


匹配成本:
  C = -p_cls(c) + λ L_box(b_pred, b_gt)


匈牙利算法: 找到总成本最小的匹配方案

为什么需要匹配：

  • 预测是无序集合，GT 也是无序集合

  • 需要建立预测与 GT 之间的一一对应

  • 未匹配的预测被分配 "无目标"（∅）类别

四、DETR 变体与改进

4.1 Deformable DETR

解决 DETR 收敛慢和小目标检测问题：

xxxxxxxxxx
标准注意力: 每个 Query 与所有位置交互（O(N²)）
Deformable 注意力: 每个 Query 仅与 K 个采样点交互（O(NK)）


采样点位置:
  通过可学习偏移量 Δp 动态调整
  关注关键区域，忽略背景

效果：

  • 训练收敛从 500 epoch 降至 50 epoch

  • 小目标检测显著提升

  • 计算效率提高 10 倍

4.2 RT-DETR：实时端到端检测

RT-DETR 是百度于 2023 年提出的实时 DETR，首次实现 Transformer 检测器的实时性能：

4.2.1 高效混合编码器

xxxxxxxxxx
标准 Transformer 编码器: 所有尺度特征统一处理（计算冗余）


RT-DETR 混合编码器:
  ├── AIFI（Attention-based Intra-scale Interaction）
  │   └── 单尺度自注意力，捕捉尺度内关系
  └── CCFF（CNN-based Cross-scale Feature Fusion）
      └── 卷积跨尺度融合，高效整合多尺度信息


效果: 计算量减少 49%，精度损失 < 1%

4.2.2 不确定性最小查询选择

xxxxxxxxxx
问题: 编码器特征质量参差不齐，低质量特征被选为查询会导致检测失败


解决方案:
  - 显式优化查询的不确定性
  - 选择高置信度、低不确定性的特征作为初始查询
  - 为解码器提供高质量的起点

六、2026 年趋势：融合与演进

6.1 YOLO × Transformer 融合

2026 年的重要趋势是将 Transformer 的全局建模能力融入 YOLO 的高效框架：

xxxxxxxxxx
YOLOv10 + Transformer Encoder:
  Backbone: CSPDarknet（保留）
  Neck: FPN + Transformer 编码器（新增全局注意力）
  Head: 解耦头 + 一致双分配


效果:
  - 保持 YOLO 的速度优势
  - 增强遮挡和密集场景检测
  - 不依赖 NMS 的端到端输出

6.2 端到端实时检测的统一范式

6.3 关键发展方向

  • 无 NMS 成为标配：YOLOv10/26 和 DETR 系列均消除 NMS，推理延迟更稳定

  • 大模型预训练：DINOv2/DINOv3 作为骨干，提升特征质量

  • 多任务统一：检测 + 分割 + 姿态 + 开放词汇的统一框架

  • 神经架构搜索（NAS）：RF-DETR 使用 NAS 自动优化架构

  • 硬件协同设计：针对特定芯片（NPU/TPU）的架构优化

七、总结

目标检测领域正经历从"手工设计组件"到"端到端学习"的范式转移。YOLO 系列通过持续工程优化保持速度优势，DETR 系列通过 Transformer 的全局建模能力实现更简洁的架构。2026 年的关键突破是两者在性能上的交汇——YOLO26 实现了无 NMS 的端到端实时检测，RT-DETR/RF-DETR 系列在精度上持续领先。未来的目标检测器将融合 CNN 的局部效率和 Transformer 的全局能力，在速度、精度和简洁性之间达到新的平衡。
