扩散模型原理详解

一、概述

扩散模型（Diffusion Model）是近年来最具影响力的生成模型之一，在图像生成、音频合成、视频生成等领域取得了突破性进展。其核心思想源于非平衡热力学：通过定义一个前向加噪过程将数据逐步转化为纯噪声，再学习一个反向去噪过程从噪声中恢复数据。这一"破坏-重建"的范式使得模型能够学习复杂数据分布的精细结构。

扩散模型的经典实现是 DDPM（Denoising Diffusion Probabilistic Models），由 Ho 等人于 2020 年提出。后续发展包括基于分数的生成模型、DDIM 加速采样、Latent Diffusion（Stable Diffusion）、Flow Matching 以及 Diffusion Transformer（DiT）等变体，它们共享相同的数学基础但采用不同的实现路径。

二、前向加噪过程（Forward Process）

2.1 马尔可夫链定义

前向过程是一个固定、无需训练的马尔可夫链，逐步向原始数据 x₀ 添加高斯噪声：

q(x_t | x_{t-1}) = N(x_t; √(1-β_t) x_{t-1}, β_t I)

其中：

  • x₀ ~ q(x₀)：原始数据分布

  • β_t ∈ (0, 1)：噪声调度参数，控制第 t 步添加的噪声量

  • T：总步数，通常设为 1000

  • 随着 t 增大，β_t 逐渐增大（如从 10⁻⁴ 增至 0.02）

2.2 重参数化：一步采样任意时刻

由于每一步都是高斯分布的叠加，可以利用重参数化技巧直接从 x₀ 计算任意时刻 t 的 x_t，无需逐步迭代：

定义：

  • αt = 1 - βt（保真性系数）

  • ᾱt = ∏{i=1}^t α_i（累积保真性系数）

则：

xxxxxxxxxx
x_t = √ᾱ_t x₀ + √(1-ᾱ_t) ε,   其中 ε ~ N(0, I)

推导：

由马尔可夫性质，x_t 可表示为 x₀ 和 t 个独立高斯噪声的线性组合：

xxxxxxxxxx
x_t = √(ᾱ_t) x₀ + √(1-ᾱ_t) ε

其中 ᾱt = ∏{i=1}^t (1-βi)。当 T 足够大时，ᾱT ≈ 0，因此 x_T ≈ ε ~ N(0, I)，即纯高斯噪声。

噪声调度 β_t 的设计直接影响模型性能：

2.4 前向过程的关键特性

  • 无需训练：前向过程是预定义的，不涉及任何可学习参数

  • 任意时刻可计算：通过重参数化，可直接采样任意 t 对应的 x_t

  • 可逆性：理论上，如果知道 x₀，前向过程完全可逆

  • 收敛性：当 t → T 时，x_t 的分布趋近于标准高斯分布 N(0, I)

三、反向去噪过程（Reverse Process）

3.1 问题定义

反向过程的目标是：给定 x_t，估计 x_{t-1} 的分布，最终从 x_T ~ N(0, I) 恢复出 x₀ ~ q(x₀)。

根据贝叶斯定理，真实的反向条件分布为：

xxxxxxxxxx
q(x_{t-1} | x_t) = q(x_t | x_{t-1}) q(x_{t-1}) / q(x_t)

但 q(x_{t-1}) 和 q(x_t) 是未知的边际分布，直接计算不可行。

3.2 关键洞察：条件于 x₀ 的后验

DDPM 的核心洞察是：虽然 q(x{t-1} | x_t) 未知，但**条件于 x₀ 的后验 q(x{t-1} | x_t, x₀) 有闭式解**：

xxxxxxxxxx
q(x_{t-1} | x_t, x₀) = N(x_{t-1}; μ̃_t(x_t, x₀), β̃_t I)

其中：

​x
μ̃_t = (√ᾱ_{t-1} β_t) / (1-ᾱ_t) × x₀ + (√α_t (1-ᾱ_{t-1})) / (1-ᾱ_t) × x_t


β̃_t = (1-ᾱ_{t-1}) β_t / (1-ᾱ_t)

3.3 用噪声预测替代 x₀ 预测

由于 x₀ 未知，我们需要用神经网络来估计。关键观察：x_t 的表达式中包含 x₀ 和噪声 ε：

xxxxxxxxxx
x_t = √ᾱ_t x₀ + √(1-ᾱ_t) ε

可以解出：

xxxxxxxxxx
x₀ = (x_t - √(1-ᾱ_t) ε) / √ᾱ_t

将其代入 μ̃_t 的表达式，经过代数变换得到：

xxxxxxxxxx
μ̃_t = (1/√α_t) × (x_t - (β_t / √(1-ᾱ_t)) × ε)

核心结论：只要神经网络能预测出噪声 ε，就能计算出均值 μ̃_t！

3.4 反向过程的参数化

定义神经网络 ε_θ(x_t, t) 来预测噪声，反向过程近似为：

xxxxxxxxxx
p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), σ_t² I)

其中：

xxxxxxxxxx
μ_θ(x_t, t) = (1/√α_t) × (x_t - (β_t / √(1-ᾱ_t)) × ε_θ(x_t, t))

方差 σt² 可以是固定的（σt² = β_t），也可以是可学习的。

3.5 采样算法（DDPM）

xxxxxxxxxx
算法：DDPM 采样
─────────────────
输入：训练好的噪声预测网络 ε_θ
输出：生成的样本 x₀


1. 从标准高斯分布采样 x_T ~ N(0, I)
2. for t = T, T-1, ..., 1:
3.   如果 t > 1:
4.     z ~ N(0, I)
5.   否则：
6.     z = 0
7.   x_{t-1} = (1/√α_t) × (x_t - (β_t/√(1-ᾱ_t)) × ε_θ(x_t, t)) + σ_t × z
8. return x₀

四、训练目标

4.1 简化训练损失

DDPM 的训练目标是最大化变分下界（ELBO），但经过推导可以简化为预测噪声的均方误差：

xxxxxxxxxx
L_simple = E_{x₀~q(x₀), ε~N(0,I), t~Uniform(1,T)} [||ε - ε_θ(x_t, t)||²]

其中 x_t = √ᾱt x₀ + √(1-ᾱt) ε。

为什么这个损失有效：

  • 网络输入的是加噪后的数据 x_t 和时间步 t

  • 网络需要预测的是添加的真实噪声 ε

  • 损失直接比较预测噪声与真实噪声的差异

  • 这比预测原始数据 x₀ 或均值 μ̃_t 更稳定

4.2 训练算法

xxxxxxxxxx
算法：DDPM 训练
─────────────────
输入：数据集 D，噪声调度 {β_t}
输出：训练好的噪声预测网络 ε_θ


重复直到收敛：
  1. 从数据集采样 x₀ ~ q(x₀)
  2. 均匀采样时间步 t ~ Uniform({1, 2, ..., T})
  3. 采样噪声 ε ~ N(0, I)
  4. 计算加噪样本：x_t = √ᾱ_t x₀ + √(1-ᾱ_t) ε
  5. 计算损失：L = ||ε - ε_θ(x_t, t)||²
  6. 梯度下降更新 θ

4.3 损失函数的等价形式

噪声预测损失等价于以下形式：

x₀ 预测形式：

xxxxxxxxxx
L = E[||x₀ - x̂_θ(x_t, t)||²_{加权}]

分数匹配形式（见第五节）：

xxxxxxxxxx
L = E[||∇_{x_t} log q(x_t | x₀) - s_θ(x_t, t)||²]

其中 sθ(x_t, t) ≈ ∇{x_t} log q(x_t) 称为分数函数（Score Function）。

五、基于分数的视角（Score-Based Generative Modeling）

5.1 分数函数定义

分数函数是数据对数概率密度的梯度：

xxxxxxxxxx
s(x_t, t) = ∇_{x_t} log q_t(x_t)

它指示了在数据空间中"概率密度增长最快的方向"。

5.2 分数与噪声预测的关系

由前向过程的定义 q(x_t | x₀) = N(x_t; √ᾱt x₀, (1-ᾱt)I)，可得：

xxxxxxxxxx
∇_{x_t} log q(x_t | x₀) = - (x_t - √ᾱ_t x₀) / (1-ᾱ_t) = - ε / √(1-ᾱ_t)

因此：

xxxxxxxxxx
ε_θ(x_t, t) ≈ ε = -√(1-ᾱ_t) × ∇_{x_t} log q(x_t | x₀)

即噪声预测网络实际上在学习条件分数函数（乘以缩放因子）。

5.3 连续时间形式：随机微分方程（SDE）

将离散时间步推广到连续时间，前向过程可表示为 SDE：

xxxxxxxxxx
dx = f(x, t) dt + g(t) dw

其中：

  • f(x, t)：漂移系数（通常 f(x, t) = -½ β(t) x）

  • g(t)：扩散系数（通常 g(t) = √β(t)）

  • dw：维纳过程（布朗运动）

5.4 反向时间 SDE

根据 Anderson 1982 的理论，反向过程满足反向时间 SDE：

xxxxxxxxxx
dx = [f(x, t) - g(t)² ∇_x log p_t(x)] dt + g(t) dẇ

其中：

  • ∇_x log p_t(x)：分数函数（由神经网络近似）

  • dẇ：反向时间的维纳过程

  • 注意：反向过程仍然包含随机项（g(t) dẇ）

5.5 概率流 ODE（Probability Flow ODE）

Song 等人发现，存在一个确定性的常微分方程，与 SDE 共享相同的边际分布：

xxxxxxxxxx
dx = [f(x, t) - ½ g(t)² ∇_x log p_t(x)] dt

这就是概率流 ODE，它是确定性的（无随机项），可用于：

  • 精确似然计算

  • 确定性采样（DDIM 的基础）

  • 更高效的数值积分

六、DDIM：确定性加速采样

6.1 核心思想

DDPM 的一个严重缺陷是需要 T=1000 步才能获得高质量样本，推理极慢。DDIM（Denoising Diffusion Implicit Models）的关键洞察是：反向过程不必是马尔可夫的。

DDIM 定义了一个非马尔可夫的生成过程，其中 x{t-1} 可以直接依赖于 x_t 和 εθ(x_t, t)，跳过中间的随机步骤。

6.2 DDIM 采样公式

xxxxxxxxxx
x_{t-1} = √ᾱ_{t-1} × (x_t - √(1-ᾱ_t) ε_θ(x_t, t)) / √ᾱ_t + √(1-ᾱ_{t-1}) ε_θ(x_t, t)

这个公式可以重写为：

xxxxxxxxxx
x_{t-1} = √ᾱ_{t-1} x̂₀ + √(1-ᾱ_{t-1}) ε_θ(x_t, t)

其中 x̂₀ = (x_t - √(1-ᾱt) εθ(x_t, t)) / √ᾱ_t 是 x₀ 的估计。

6.3 DDIM 的关键特性

  • 确定性：给定 x_T 和模型，生成过程完全确定

  • 加速采样：可用 20~50 步达到 DDPM 1000 步的效果

  • 一致性：同一初始噪声生成相似样本，便于插值和编辑

  • 训练兼容：使用与 DDPM 完全相同的训练目标，无需重新训练

6.4 广义采样族

DDIM 是更一般采样族的一个特例。定义：

xxxxxxxxxx
σ_t = η × √((1-ᾱ_{t-1})/(1-ᾱ_t)) × √(1-ᾱ_t/ᾱ_{t-1})

  • η = 1：恢复 DDPM（随机采样）

  • η = 0：DDIM（确定性采样）

  • 0 < η < 1：介于两者之间的随机性程度

七、条件生成与引导

7.1 分类器引导（Classifier Guidance）

在条件生成中，我们希望生成特定类别的样本。分类器引导利用预训练的分类器来引导采样：

xxxxxxxxxx
ε̃_θ(x_t, t, c) = ε_θ(x_t, t) - w × √(1-ᾱ_t) × ∇_{x_t} log p_φ(c | x_t)

其中：

  • p_φ(c | x_t)：预训练分类器对类别 c 的概率

  • w：引导强度（w > 1 增强条件信号）

  • ∇{x_t} log pφ(c | x_t)：分类器梯度，指向"更像类别 c"的方向

7.2 无分类器引导（Classifier-Free Guidance）

分类器引导需要额外训练分类器。无分类器引导通过联合训练条件和非条件模型来避免这一需求：

xxxxxxxxxx
ε̃_θ(x_t, t, c) = ε_θ(x_t, t, ∅) + w × (ε_θ(x_t, t, c) - ε_θ(x_t, t, ∅))

其中：

  • ε_θ(x_t, t, c)：条件预测（给定类别 c）

  • ε_θ(x_t, t, ∅)：非条件预测（类别信息被随机丢弃）

  • w：引导强度，通常 1.5~7.5

直观理解：将预测从"无条件"方向推向"条件"方向，w 越大，生成样本越符合条件但多样性降低。

7.3 训练时的随机丢弃

训练时，以概率 p_uncond（通常 0.1）将条件信息替换为空标记 ∅：

xxxxxxxxxx
c' = { c,           概率 1 - p_uncond
     { ∅,           概率 p_uncond

这使得模型同时学会条件生成和非条件生成。

八、Latent Diffusion（Stable Diffusion）

8.1 核心思想

直接在像素空间（如 512×512×3 = 786,432 维）进行扩散计算量巨大。Latent Diffusion 在压缩的潜在空间中进行扩散，大幅降低计算成本。

8.2 架构

xxxxxxxxxx
图像空间                    潜在空间
   │                          │
   ├──→ VAE Encoder ──→ z₀ ──┤
   │         (压缩 4~8×)      │
   │                          ├──→ 扩散过程（在潜在空间）
   │                          │      z_T → ... → z₀
   │                          │
   └──← VAE Decoder ←─ z₀ ───┘
            (重建)

  • VAE Encoder：将图像压缩为低维潜在表示 z（如 64×64×4）

  • 扩散过程：在潜在空间中进行前向加噪和反向去噪

  • VAE Decoder：将潜在表示解码回像素空间

8.3 优势

  • 计算效率：潜在空间维度降低 4~8 倍，训练和推理速度大幅提升

  • 语义丰富：VAE 的潜在空间具有更好的语义结构

  • 跨模态：易于结合文本条件（通过 CLIP 等编码器）

十、总结

扩散模型的数学基础可概括为以下核心链条：

xxxxxxxxxx
前向过程（加噪）
    q(x_t | x_{t-1}) = N(x_t; √(1-β_t)x_{t-1}, β_t I)
         ↓ 重参数化
    x_t = √ᾱ_t x₀ + √(1-ᾱ_t) ε
         ↓ 贝叶斯推导
    q(x_{t-1} | x_t, x₀) = N(x_{t-1}; μ̃_t, β̃_t I)
         ↓ 噪声预测参数化
    μ̃_t = (1/√α_t)(x_t - (β_t/√(1-ᾱ_t))ε)
         ↓ 神经网络近似
    ε_θ(x_t, t) ≈ ε
         ↓ 训练
    L = E[||ε - ε_θ(x_t, t)||²]
         ↓ 采样
    x_{t-1} = μ_θ(x_t, t) + σ_t z

扩散模型的优雅之处在于：

  1. 前向过程简单可逆：纯高斯噪声叠加，有闭式解

  2. 反向过程转化为噪声预测：避免了直接建模复杂分布

  3. 训练目标简洁稳定：均方误差损失，无需对抗训练

  4. 理论框架统一：DDPM、分数匹配、SDE/ODE 本质等价

  5. 可扩展性强：易于加入条件引导、潜在空间、跨模态等扩展

从热力学扩散到深度生成模型，扩散模型将"无序到有序"的物理直觉转化为可计算的数学框架，成为当前生成式 AI 的核心支柱之一。
