3D 生成技术详解：NeRF、Gaussian Splatting 与三维重建

一、概述

三维场景重建与渲染是计算机视觉和计算机图形学的核心问题。传统方法依赖显式几何表示（如网格、点云、体素），而近年来神经辐射场（NeRF）和 3D 高斯泼溅（3D Gaussian Splatting, 3DGS）开创了基于学习的隐式/显式混合表示新范式。这两种技术都能从多视角二维图像重建三维场景并合成新视角，但在表示方式、渲染效率和可编辑性上存在本质差异。

二、NeRF（Neural Radiance Fields，神经辐射场）

2.1 核心思想

NeRF 由 Mildenhall 等人于 2020 年提出，其核心思想是将三维场景编码为一个连续的体积函数，该函数由神经网络参数化。给定空间中的一个 5D 坐标（3D 位置 + 2D 观察方向），网络输出该点的颜色（RGB）和体积密度（不透明度），通过体渲染技术将沿光线的采样值合成为像素颜色。

2.2 数学定义

​x
输入: 5D 坐标 (x, y, z, θ, φ)
    ↓
MLP 网络 F_θ
    ↓
输出: (c, σ) = F_θ(x, y, z, θ, φ)


其中:
- c = (r, g, b): 发射颜色（视角相关）
- σ: 体积密度（视角无关）
- θ, φ: 观察方向的球坐标角度

2.3 体渲染方程

对于每条相机光线 r(t) = o + t·d，像素颜色通过积分计算：

xxxxxxxxxx
C(r) = ∫_{t_n}^{t_f} T(t) σ(r(t)) c(r(t), d) dt


其中:
- T(t) = exp(-∫_{t_n}^{t} σ(r(s)) ds): 累积透射率
- σ(r(t)): 点 r(t) 处的密度
- c(r(t), d): 点 r(t) 沿方向 d 的颜色
- t_n, t_f: 近/远边界

离散化近似（实际实现）：

xxxxxxxxxx
Ĉ(r) = Σ_{i=1}^{N} T_i (1 - exp(-σ_i δ_i)) c_i


其中:
- T_i = exp(-Σ_{j=1}^{i-1} σ_j δ_j)
- δ_i = t_{i+1} - t_i: 采样点间距

2.4 位置编码（Positional Encoding）

NeRF 使用高频位置编码克服 MLP 的平滑性偏置：

xxxxxxxxxx
γ(p) = [sin(2⁰πp), cos(2⁰πp), sin(2¹πp), cos(2¹πp), ..., sin(2^{L-1}πp), cos(2^{L-1}πp)]


其中 L=10 用于位置 (x,y,z)，L=4 用于方向 (θ,φ)

这使得 MLP 能够学习高频细节，避免输出过于平滑。

2.5 训练流程

xxxxxxxxxx
输入: 多视角图像 + 相机位姿（由 COLMAP SfM 估计）


重复直到收敛:
  1. 随机采样一批像素/光线
  2. 沿每条光线均匀采样 N 个 3D 点
  3. 对每个点，MLP 预测 (c, σ)

  5. 损失: L = Σ ||Ĉ(r) - C_gt(r)||²

三、3D Gaussian Splatting（3D 高斯泼溅）

3.1 核心思想

3DGS 由 Kerbl 等人于 2023 年提出，其核心思想是用显式的 3D 高斯椭球集合替代隐式神经网络来表示场景。每个高斯基元携带位置、协方差（形状与朝向）、不透明度和球谐函数（SH）编码的视角相关颜色。通过可微分的光栅化渲染，实现从 3D 高斯到 2D 屏幕像素的高效投影与混合（"泼溅"过程）。

3.2 3D 高斯表示

每个高斯基元由以下参数定义：

xxxxxxxxxx
G_i(x) = exp(-½ (x - μ_i)^T Σ_i^{-1} (x - μ_i))


参数:
- μ_i ∈ R³: 中心位置
- Σ_i ∈ R^{3×3}: 协方差矩阵（控制形状和朝向）
- α_i ∈ [0,1]: 不透明度
- c_i: 颜色（由球谐函数 SH 编码，视角相关）

协方差矩阵通过缩放矩阵 S 和旋转矩阵 R 分解：

xxxxxxxxxx
Σ = R S S^T R^T


其中:
- S = diag(s_x, s_y, s_z): 各轴缩放
- R: 旋转四元数表示

3.3 渲染管线

3.3.1 投影到 2D

将 3D 高斯投影到相机图像平面，得到 2D 高斯：

xxxxxxxxxx
Σ' = J W Σ W^T J^T


其中:
- W: 世界到相机的变换矩阵
- J: 投影变换的雅可比矩阵

3.3.2 α-混合（Alpha Blending）

按深度排序后，从前到后混合所有 2D 高斯：

xxxxxxxxxx
C(p) = Σ_{i∈N} c_i α_i G'_i(p) ∏_{j=1}^{i-1} (1 - α_j G'_j(p))


其中:
- G'_i(p): 像素 p 处第 i 个 2D 高斯的值
- α_i: 不透明度
- 乘积项: 累积透射率（前方高斯的遮挡效应）

3.3.3 分块光栅化（Tile-Based Rasterization）

为实现实时渲染，3DGS 采用分块策略：

xxxxxxxxxx
1. 将屏幕划分为 16×16 像素的瓦片（Tiles）
2. 对每个 3D 高斯，计算其覆盖的瓦片
3. 每个瓦片内按深度排序高斯
4. 并行渲染每个瓦片，α-混合贡献
5. 仅计算概率密度大于阈值（3σ 范围）的像素

3.4 训练流程

xxxxxxxxxx
输入: 多视角图像 + COLMAP 估计的相机位姿和稀疏点云


初始化:
  - 每个 SfM 点初始化一个 3D 高斯
  - 协方差由最近邻距离估计


重复直到收敛:
  1. 渲染当前视角图像（分块光栅化）
  2. 计算损失: L = (1-λ) L1 + λ L_SSIM
  3. 反向传播梯度到高斯参数 (μ, Σ, α, SH)
  4. 自适应密度控制:
     - 欠重建区域: 克隆高斯（复制并沿梯度移动）
     - 过重建区域: 分割高斯（替换为两个更小的高斯）
     - 透明高斯: 删除（α < 阈值）

五、三维重建流程

5.1 标准重建管线

xxxxxxxxxx
阶段 1: 数据采集
├── 拍摄多视角图像（建议 50~200 张）
├── 覆盖目标物体的各个角度
├── 保持光照相对稳定
└── 图像分辨率建议 ≥ 1080p


阶段 2: 相机位姿估计（SfM）
├── 使用 COLMAP 进行 Structure from Motion
├── 输出: 相机内参、外参（位姿）、稀疏点云
└── 耗时: 数分钟到数小时（取决于图像数量）


阶段 3: 辐射场重建
├── NeRF 路径: 训练 MLP 网络
├── 3DGS 路径: 初始化高斯 + 优化
└── 耗时: 数分钟（3DGS/Instant-NGP）到数小时（原始 NeRF）


阶段 4: 新视角合成
├── 指定任意相机位姿
├── 渲染对应视角的图像
└── 评估: PSNR, SSIM, LPIPS


阶段 5: 导出与应用
├── NeRF: 导出网络权重
├── 3DGS: 导出 PLY 文件（含高斯参数）
└── 集成到 Web/VR/AR/游戏引擎

八、总结

NeRF 和 3D Gaussian Splatting 代表了三维重建的两种哲学：NeRF 追求"用神经网络记忆场景"的优雅简洁，3DGS 追求"用显式基元高效渲染"的实用高效。2026 年的实践中，3DGS 凭借其实时渲染能力和可编辑性已成为工业应用的主流选择，而 NeRF 及其改进方法仍在高质量渲染和理论研究中保持重要地位。两者的融合与互补，正在推动三维视觉技术从"离线制作"走向"实时交互"的新阶段。
